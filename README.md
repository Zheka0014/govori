# Говори по-английски

Голосовой учитель английского для телефона: живой разговор, исправление ошибок и произношения, объяснения по-русски.

Открыть: https://zheka0014.github.io/govori/

## Как это работает

- Страница соединяется напрямую с Gemini Live API от Google: звук с микрофона идёт в Google, голос учителя приходит обратно.
- Нужен личный бесплатный ключ Google. Он создаётся на https://aistudio.google.com/apikey и вставляется на первом экране.
- Ключ, словарь и список ошибок хранятся только в браузере на устройстве. В этом репозитории ключей нет.

## Файлы

- `index.html` — всё приложение в одном файле.
- `manifest.webmanifest`, `icon-*.png` — чтобы страницу можно было добавить на главный экран телефона.
